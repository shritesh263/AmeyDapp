# Contributing to BlackBox AI

Thank you for your interest in contributing to **BlackBox AI**!

## Development Workflow

1. Fork & clone the repository.
2. Install dependencies:
   ```bash
   npm install
   cd frontend && npm install && cd ..
   ```
3. Run test suite:
   ```bash
   npm test
   ```
4. Build and verify:
   ```bash
   npm run build
   npm run frontend:build
   ```
5. Submit a pull request with clear descriptions and test coverage.
